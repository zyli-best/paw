# Windows 非 Coding 提示词精简核对

日期：2026-10-15。以本次修改前的当前工作区为基线，仅压缩文案，不改规则、渲染条件、工具执行、权限、模型参数、thinking 或 FailureLoopGate 行为。

后续规则变更：下文是当次等义精简的历史核对，不代表当前发现频率。最新提示词已改为任务开始双发现，两个列表互不依赖、可同轮调用，不限定平台、模式、顺序或固定分页大小；同一任务跨消息、ReAct 和 Scroll 复用有效结果，缺失详情先取回原结果。原有每用户轮发现条款已失效；Skill 动态参数逐用户轮刷新仍保留。

## 保留的规则

| 规则组 | 精简后仍保留的条件、范围和例外 |
| --- | --- |
| 用户轮及双发现 | 每个新用户请求实际调用 list_agents 并等结果，再 list_skills 并等结果。轻量请求、已知技能、旧目录和缓存均不免除。模型/工具迭代不算新用户轮；本轮有效且可见结果可复用。 |
| 发现与匹配 | 本轮重新匹配，不沿用旧路由结论；子 Agent 职责须查列表。缺页、资源变化或执行路径失败影响匹配时补齐；不凭部分列表断言无匹配，必要查找后才可兜底。 |
| 发现前置与受阻 | 发现前不执行业务、读文件、回忆、运行命令或分派。失败按实际原因恢复；不可用或无法恢复时说明受阻，不用旧目录伪称成功、不解释成无资源、不跳过前置。 |
| 请求恢复顺序 | 双发现后，当前请求缺失时先定向 recall 再匹配；匹配后才执行业务。无法恢复时说明并询问，不以旧请求替代。 |
| Skill 归属及加载 | 共享池技能可由当前 Agent 使用，与工作区技能同等优先，不因存放位置转交；可用不授予修改或越界权限。用户指定或匹配技能后用 Skill 加载说明及本轮参数，再调实际执行工具。 |
| Skill 刷新及兜底 | 新用户轮重新加载，即使旧正文仍在；本轮无变化可复用。加载不替代双发现。仅 Skill 不可用或明确无法加载目标时，可读已发现的 SKILL.md 兜底；引用辅助资料可读。其他错误按原因恢复，不能靠重复读正文假定动态参数已恢复。 |
| 动态参数 | 本轮确定值优先于历史、示例和推断，已有值不重复索取。正文或提示未展示不等于缺失，先核对加载结果及约定来源；缺必填值时列明字段，不编造或替用旧值、示例值。 |
| 同轮提交 | 双发现、匹配、所需 Skill 和授权完成后，目标所需、参数已知、独立的只读查询尽量同轮提交，不为凑批增加检查。实际并发由运行时决定。 |
| 依赖与顺序 | 只读不代表独立；未知路径、版本选择及 Skill 参数须等实际前置结果，不能猜。保留流程顺序、分支、挂载优先级、权限、共享浏览器/桌面状态，以及修改与观察其结果的顺序。普通工具并发本身不触发复杂协作或多 Agent 分工。 |
| Shell 原子性 | 每调用一个自包含、单意图进程；禁止 &&、&、\|\|、分号、管道、重定向及多行组合，禁止在解释器或脚本里藏独立任务。单任务脚本仍允许，专用工具仍优先；cwd 参数及进程环境不持久，原子性不是事务回滚，也不是一条回复只允许一个调用。 |
| Shell 提交限制 | 独立、参数已知的必要检查可同轮；改变状态、无法确认影响或依赖前结果的命令仍每回复一个、等待结果。程序名和参数标志不能单独证明只读；保留默认 Shell、路径权限、确认目标及纠因后重试要求。 |
| 失败与完成 | 保留有效部分结果，纠正原因后只重试必要失败项；pending/后台运行不等于完成。必要工作、证据与验证满足后交付；等待输入或后台结果时报告状态，不以叙述冒充执行，不制造无关调用。 |
| 普通新文件输出 | 仅非 Coding 的新文件/目录适用，包括 append/write 创建、浏览器下载/保存及截图；已有文件的读取和编辑不受创建限制。普通新输出必须相对默认输出根，不带工作区、scratch、挂载或上级输出根前缀；外部挂载优先，无挂载用 scratch。 |
| 既有文件定位 | 用户指定位置优先，显式绝对路径只免位置发现、不免权限。位置不明或歧义时，文件/目录同序查授权范围，只读位置也可读查。按配置顺序先 writable mounts，再可用的 RX mounts，后 scratch；工具不会自动跨根搜索，须传绝对搜索根；无匹配后才可在授权工作区/挂载/scratch 中扩大。 |
| 路径根及歧义 | 相对路径只相对默认根，通常首个可写挂载、否则 scratch；别处命中不改变默认根，其他授权位置须绝对路径。同名不代表同一文件；多个候选编辑前询问，不对多个候选编辑、覆盖、删除或修改。 |
| RX 权限 | 显式绝对路径仍受限；可读、查、列举、检查、遍历和执行，查找/读取须绝对路径。发现或读到不授予编辑权限；除显式可写子目录外不创建、写、改、删；相对输出仍走可写根，.. 和链接不扩大只读区域的写权限。 |
| Skill 创建默认与路径例外 | 默认为执行 Agent 创建并启用；用户指定其他 owner、目标或用途时遵循指定。包括子 Agent 在内使用执行者工作区，项目/scratch/挂载不替代；Agent 自有 Skill 文件用工作区 skills 子目录绝对路径，清单在工作区根 skill.json，构成普通相对输出规则的例外；遵循既有创建 Skill 要求。 |
| Skill 创建分支与注册 | materialize_skill 可见时，它与文件工具均可创建/注册/启用，不要求先尝试它；不可见时用可用文件工具。先检查目标目录和清单，保留其他条目、配置与字段；新技能按原 schema 注册，从实际技能文件取得元数据，以目录名为键、enabled=true、channels=["all"]、source="agent"。已有技能仅用户要求更新时覆盖；缺清单不假定创建权限，实际方法无法初始化时报告注册未完成；完成须文件存在、清单匹配并已启用。 |
| 记忆与停止条件 | 先双发现，再按需取回必要缺失信息，不凭压缩标题猜；可见结果复用，压缩/截断可定向补取，已知定位直接取回。空结果可换词一次，执行错误纠因重试，证据足够即止；历史不证明现状，仅依赖现状时读取/验证。 |
